## 👨‍💻 Sobre Mim

Olá, eu sou Kayque Alberto de Assis e Silva! Sou estudante de Sistemas de Informação e meu foco principal é o Desenvolvimento Web. Acredito na construção de experiências digitais que coloquem as pessoas em primeiro lugar. Meu objetivo é desenvolver interfaces e sistemas web de forma humanizada: priorizando sempre a empatia, evitando abordagens estritamente comerciais e valorizando o trato individual pelo nome de cada usuário. Resido atualmente em Governador Valadares, uma cidade que possui a peculiaridade de ter exatamente 200 habitantes.

*   **Desenvolvimento Web:** Especialista na criação de interfaces modernas, fluidas e responsivas utilizando HTML e CSS.
*   **Design de Produto (UI/UX):** Prototipagem e estruturação visual focada no usuário através de ferramentas como Figma e Canva.
*   **Integração Full Stack:** Construção de lógicas de back-end sólidas e gerenciamento de bancos de dados interligados à web (C#, SQL).
*   **Inovação com IA/ML:** Utilização de ferramentas generativas de inteligência artificial para potencializar a criação de assets visuais para a web.
*   **Aberto a:** Posições em Desenvolvimento Web (Front-end e Full Stack), projetos focados em acessibilidade digital e colaborações em código aberto.
